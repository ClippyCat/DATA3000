## 5. Use the definition of Big-Oh notation only to prove that the following statements are false:
### a) $\dfrac{5n^3 \log(n+1)}{n^2 + 1000}$ is in $O(\log n)$

Let $f(n) = \dfrac{5n^3 \log(n+1)}{n^2 + 1000}$ and $g(n) = \log n$.

**Assume the opposite.**

There exist $c > 0$ and $n_0$
such that $f(n) \le c \log n$ for all $n \ge n_0$.

**Bound the denominator from above so we can  bound $f(n)$ from
below.**

When $n \ge 32$ we have $n^2 \ge 1024 > 1000$, therefore

$$n^2 + 1000 \le n^2 + n^2 = 2n^2.$$

For $n \ge 32$:

$$f(n) = \frac{5n^3 \log(n+1)}{n^2 + 1000}
      \ge \frac{5n^3 \log(n+1)}{2n^2}
      = \frac{5}{2}\, n \log(n+1).$$

Since $\log(n+1) \ge \log n > 0$ for $n \ge 2$, we get for all $n \ge 32$:

$$f(n) \ge \frac{5}{2}\, n \log n.$$

**Combine with the assumption.**
For every $n \ge N$, where
$N = \max(n_0, 32)$, both bounds hold at once:

$$\frac{5}{2}\, n \log n \;\le\; f(n) \;\le\; c \log n.$$

Because $n \ge 32 > 1$, we have $\log n > 0$, so divide through by
$\log n$:

$$\frac{5}{2}\, n \le c.$$

**Contradiction.**
This claims $n \le \tfrac{2}{5} c$ for every
$n \ge N$.

But $c$ is fixed while $n$ can be arbitrarily large.

Choosing any $n \ge \max\!\left(N,\ \tfrac{2}{5}c + 1\right)$ violates it.

So no constants $c$ and $n_0$ can exist.


$$\frac{5n^3 \log(n+1)}{n^2 + 1000} \notin O(\log n). \qquad \blacksquare$$

### b) $\log n + \sqrt{n}$ is in $O(\log n)$

Let $f(n) = \log n + \sqrt{n}$ and $g(n) = \log n$.

**Assume the opposite.**

There exist $c > 0$ and $n_0$ such that
$\log n + \sqrt{n} \le c \log n$ for all $n \ge n_0$.

**Isolate the fast-growing term.**

For $n \ge 2$, $\log n > 0$.
Subtract $\log n$ from both sides:

$$\sqrt{n} \le (c - 1)\log n \quad \text{for all } n \ge \max(n_0, 2).$$

(This already forces $c > 1$, otherwise the right side is $\le 0$ while the
left side is positive.)

**This is impossible.**

Substitute $m = \log_2 n$, i.e.
$n = 2^m$. Then $\sqrt{n} = 2^{m/2}$ and $\log_2 n = m$, so the inequality
becomes

$$2^{m/2} \le (c - 1)\,m.$$

The left side grows exponentially in $m$, the right side only linearly. For large $m$ the exponential overtakes any fixed multiple of
$m$, so the inequality fails.

Equivalently, the ratio

$$\frac{\sqrt{n}}{\log n} = \frac{2^{m/2}}{m} \longrightarrow \infty,$$

so it cannot stay below the constant $c - 1$.

**Contradiction.**
Since $\sqrt{n} \le (c-1)\log n$ fails for large
$n$, no constants $c$ and $n_0$ work.

Therefore

$$\log n + \sqrt{n} \notin O(\log n). \qquad \blacksquare$$

## 6. Determine whether the first function in each of the following pairs has a larger, smaller, or the same growth rate as the second function:

### a) $n(n+1)$ vs $2000\,n^2$

Expand the first: $n(n+1) = n^2 + n$. Form the ratio:

$$\frac{n^2 + n}{2000\,n^2} = \frac{1 + \tfrac{1}{n}}{2000}
  \longrightarrow \frac{1}{2000} \quad \text{as } n \to \infty.$$

The limit is a finite positive constant, so both are $\Theta(n^2)$.

**the first function has the same growth rate as the second function.**

### b) $100\,n^2$ vs $0.01\,n^3$

$$\frac{100\,n^2}{0.01\,n^3} = \frac{10000}{n}
  \longrightarrow 0 \quad \text{as } n \to \infty.$$

The ratio goes to $0$, so the first grows more slowly. $n^2$ is a lower
power than $n^3$; the constants $100$ and $0.01$ do not change this.

**the first function has a smaller growth rate than the second function.**

### c) $(\log_2 n)^2$ vs $\log_2(n^2)$

Simplify the second $\log(n^2) = 2\log n$:

$$\log_2(n^2) = 2\log_2 n = \Theta(\log n).$$

The first is $(\log_2 n)^2 = \Theta\big((\log n)^2\big)$. Form the ratio:

$$\frac{(\log_2 n)^2}{2\log_2 n} = \frac{\log_2 n}{2}
  \longrightarrow \infty \quad \text{as } n \to \infty.$$

The ratio grows without bound.

**the first function has a larger growth rate than the second function.**
