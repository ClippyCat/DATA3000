Question 1

An algorithm takes 10 milliseconds to process 1,000 data items with time complexity O(f(n)) and running time T(n) = cf(n). If f(n) = n and f(n) = n2, how much time will be spent to process 100,000 data items? (6 marks)

Given: T(n) = cf(n), T(1000) = 10 ms, Find T(100,000)

CASE 1: f(n) = n
-----------------
Find c:
c = 10 / 1000 = 0.01

Find T(100,000):
T(100,000) = 0.01 x 100,000 = 1,000 ms (1 second)

CASE 2: f(n) = n^2
-------------------
Find c:
c = 10 / 1000^2 = 0.00001

Find T(100,000):
T(100,000) = 0.00001 x 100,000^2 = 100,000 ms (1.67 minutes)

Therefore for
f(n) = n it will take 1,000 ms (1 second) to process 100,000 data items
f(n) = n^2 it will take 100,000 ms (1.67 minutes) to process 100,000 data items

The quadratic algorithm takes 100x longer than the linear one.

Question 2
------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
An algorithm spends 1000 microseconds on 5 data items with running time T(n) = cn3. What time will be spent on 10,000 data items? (6 marks)

Given: T(n) = cn^3, T(5) = 1000 microseconds, Find T(10,000)
 
Find c:
c = 1000 / 5^3 = 1000 / 125 = 8
 
Find T(10,000):
T(10,000) = 8 x 10,000^3 = 8,000,000,000,000 ms
 
8,000,000,000,000 ms = 8,000,000 seconds = approximately 92.6 days
 
Therefore it will take approximately 92.6 days to process 10,000 data items.
